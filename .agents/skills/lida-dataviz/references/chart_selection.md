# 图表类型选择

## 按问题类型选图

| 问题类型 | 首选 | 备选 / 条件 |
|---|---|---|
| 时间趋势 | 折线图 | 时间点 ≤ 12 且强调单期数值：柱状图；多系列 > 6 条：小多图（small multiples）或只突出重点系列 |
| 类别比较 | 柱状图（按数值排序） | 类别名长或类别 > 8 个：**横向条形图**；两个维度：分组柱状图，或热力图（类别都 > 6 时） |
| 排名 / Top N | 横向条形图（降序，最大值在上） | 棒棒糖图 |
| 构成 / 占比 | 堆叠柱状图（百分比堆叠） | **≤ 5 个部分**且只有一个整体时才用饼图/环形图；随时间变化的构成：百分比堆叠面积图 |
| 分布 | 直方图 | 按组比较分布：箱线图 / 小提琴图；样本量小：带抖动的点图（strip） |
| 两变量关系 | 散点图 | 点 > 5000：hexbin 或加透明度；需要看趋势：加回归线（`sns.regplot`） |
| 多变量相关 | 相关系数热力图 | 下三角并标注数值 |
| 实际 vs 目标 | 柱状图 + 目标线（`axhline`） | 子弹图 |
| 增减变化 / 贡献拆解 | 瀑布图 | 发散条形图（以 0 为中心） |
| 地理 | 有经纬度：散点地图；只有省份/城市名：**按地区排序的条形图** | 不要硬画没有底图的地图 |

## 必须遵守的最佳实践

- **柱状图的 y 轴从 0 开始**；折线图可以不从 0 开始，但不能刻意夸大变化。
- **排序**：没有天然顺序的类别按数值排序；有天然顺序的（月份、等级、年龄段）保持原顺序。
- **类别太多**：超过 10–12 个时保留 Top N，其余合并为「其他」，并在标题或注释里说明。
- **单一数值**：问题的答案是单一值（最大、平均、中位数等）时，用 `axhline`/`axvline` 画参考线，并在图例里标注数值（保留 2 位小数）。这条来自 LIDA。
- **量级差异**：同一张图里数值跨越 3 个数量级以上时考虑对数坐标，并在轴标签里注明"（对数刻度）"。
- **双 Y 轴**：默认不用。两个量纲不同的指标用上下两个子图，共享 x 轴。
- **不用 3D 图**，不用渐变色、阴影之类的装饰。

## 时间粒度

| 数据跨度 | 推荐粒度 |
|---|---|
| < 2 个月 | 日 |
| 2 个月 – 1 年 | 周或月 |
| 1 – 5 年 | 月或季度 |
| > 5 年 | 年 |

时间点太密时，用 `matplotlib.dates` 的 locator/formatter 控制刻度数量。

## 颜色

- 单系列：只用一个颜色（例如 `#4C72B0`），不要按类别乱上色。
- 强调：重点项用强调色，其余用灰色（`#BBBBBB`）。
- 分类色板：≤ 8 类时用 `tab10` 或 seaborn 默认色板。
- 顺序型数值（热力图）：`Blues` / `viridis`。
- 有正负的数值（以 0 为中心）：`RdBu_r`，并且设置 `center=0`。
- 尽量照顾色盲用户，避免只靠红绿区分。

## 数字格式（中文场景）

- 大数换算单位：≥ 1 万显示"万"，≥ 1 亿显示"亿"，并在轴标签里写清楚单位，例如"销售额（万元）"。
- 千分位：`StrMethodFormatter("{x:,.0f}")`。
- 百分比：`PercentFormatter(1)`（数据是 0–1 的小数时）或 `PercentFormatter(100)`。
